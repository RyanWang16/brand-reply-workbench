# 品牌回复工作台

运营人员粘贴一条帖子内容，选择产品后，系统先从产品资料库检索相关信息，再交给 AI 生成品牌回复；结果会展示本次引用的资料来源，也可把帖子链接和回复整理成 Excel。

## 打开

- **Mac：** 双击 `启动工作台.command`。
- **Windows：** 双击 `启动工作台.bat`。

浏览器会自动打开生成器。使用时不要关闭随后出现的终端窗口。

## 使用

1. 粘贴小红书帖子链接、标题和正文。
2. 选择产品。
3. 点 **生成回复**，然后点 **复制文案**。
4. 点 **加入交付清单**，收集完成后点 **下载 Excel**。

Excel 每行对应一条帖子，包含帖子链接、标题、产品、回复内容和回复身份。交付清单保存在当前浏览器中；换浏览器或清理浏览器数据后不会保留。

链接只保存为来源，不会自动提取页面文字。帖子正文需要手动粘贴。

## 初次配置

管理员先将 `.env.example` 复制为 `.env`，填入 AI 服务地址、密钥和模型名称。演示产品“澄风 Lumina 轻羽吹风机”是虚构产品，完整手册在 `docs/demo_product_manual.md`。检索资料保存在 `config/product_knowledge.json`；新增资料时请填写来源，并把手册和知识库条目保持一致。

## RAG 流程

程序根据用户粘贴的帖子标题和正文，在所选产品的知识条目中做本地相关性检索，取相关资料片段交给模型生成回复。当前使用轻量中文字符片段检索，不依赖外部向量数据库；结果会显示检索到的条目和来源。检索不到相关资料时不会调用模型生成。

## 数据说明

生成内容是品牌回复建议，不会自动发布。生成时，帖子标题、正文和检索到的产品资料会发送到配置的模型服务；帖子链接不会发送。交付清单保存在当前浏览器中。虚构手册仅供演示，请勿作为真实产品事实使用。请勿粘贴个人敏感信息。
