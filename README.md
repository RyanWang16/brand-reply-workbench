# 品牌回复工作台

运营人员粘贴一条帖子内容，选择产品后生成品牌口吻的回复；可把帖子链接和回复整理成 Excel。

## 打开

- **Mac：** 双击 `启动工作台.command`。
- **Windows：** 双击 `启动工作台.bat`。

浏览器会自动打开生成器。使用时不要关闭随后出现的终端窗口。

## 使用

1. 粘贴小红书帖子链接、标题和正文。
2. 选择产品。
3. 点 **生成回复**，然后点 **复制文案**。
4. 点 **加入交付清单**，收集完成后点 **下载 Excel**。

Excel 每行对应一条帖子，包含帖子链接、标题、产品、回复内容和回复身份。交付清单保存在当前浏览器中；换浏览器或清理浏览器数据后不会保留。

链接只保存为来源，不会自动提取页面文字。帖子正文需要手动粘贴。

## 初次配置

管理员先将 `.env.example` 复制为 `.env`，填入 AI 服务地址、密钥和模型名称；再到“产品卖点”页面填写已核实的产品信息。日常使用不需要改代码。

## 数据说明

生成内容是品牌回复建议，不会自动发布。生成时，帖子标题、正文和产品卖点会发送到配置的模型服务；帖子链接不会发送。交付清单保存在当前浏览器中。请勿粘贴个人敏感信息。
